# Cozy Roads

- Python + pygame-ce game, entry point `run_game.py`, code in `cozyroads/`.
- **Bump `VERSION` in `cozyroads/version.py` on every change pushed to the default branch.**
  The in-game "Check for updates" compares it with GitHub to tell players a new version exists.
- The update check only reads the version number; it never downloads or runs code.
